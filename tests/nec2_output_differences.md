# Comparison: `tests/nec2_output_sections.md` vs `src/output.c` (Original NEC output)

## Summary

This comparison checks the Fortran-based output inventory in `tests/nec2_output_sections.md` against the current original-format implementation in `src/output.c`.

- `src/output.c` uses `ctx->output_format == OUTPUT_FORMAT_ORIGINAL` to select the original NEC output path.
- The implementation now includes explicit Fortran-style output for both the normalized gain table and the structure excitation table.
- Remaining differences are now mostly small header phrasing and spacing details rather than missing original sections.

## Original-style sections now implemented in `src/output.c`

The following original-style output sections are now implemented in `src/output.c`:

- `SURFACE PATCH DATA` via `write_patches()`
- `ANTENNA ENVIRONMENT` via `write_environment_data()`
- `NETWORK DATA` via `write_network_data()`
- `STRUCTURE EXCITATION DATA AT NETWORK CONNECTION POINTS` via `write_network_excitation()`
- `ANTENNA INPUT PARAMETERS` via `write_antenna_input_parameters()`
- `NEAR ELECTRIC FIELDS` / `NEAR MAGNETIC FIELDS` via `write_near_field_data()`
- `NORMALIZED GAIN` via `write_normalized_gain()`
- `HELIX STRUCTURE` output for GH cards via the geometry/patch output branch

These sections now include the Fortran-derived labels and row layouts for original output where applicable.

## Current exact formatting observations

### Network data

For original output, `write_network_data()` prints Fortran-style network headers and column labels in both:

- transmission line mode
- admittance matrix mode

This matches the NEC-2 Fortran `FORMAT(158)` / `FORMAT(160)` semantics with `- FROM -    - TO -` and `TAG  SEG.` labels.

### Structure excitation data

`write_network_excitation()` now prints the original Fortran section heading:

```text
- - - STRUCTURE EXCITATION DATA AT NETWORK CONNECTION POINTS - - -
```

and writes the excitation rows with the original `%12.5E` scientific formatting.

### Normalized gain

`write_normalized_gain()` now prints the original Fortran header:

```text
- - - - NORMALIZED GAIN - - - -
```

and the Fortran-style normalization factor and angle/gain label rows.

### Near-field headers

`write_near_field_data()` now prints:

```text
- - - NEAR ELECTRIC FIELDS - - -
```

or

```text
- - - NEAR MAGNETIC FIELDS - - -
```

with the original location/field label blocks.

### Antenna environment

The original branch now prints Fortran ground labels and punctuation:

```text
FINITE GROUND.  REFLECTION COEFFICIENT APPROXIMATION
FINITE GROUND.  SOMMERFELD SOLUTION
RELATIVE DIELECTRIC CONST.= %.3f
CONDUCTIVITY= %10.3E MHOS/METER
COMPLEX DIELECTRIC CONSTANT= %11.4E%+11.4Ej
```

### Helix structure output

The GH card output now begins with the classic Fortran wording:

```text
HELIX STRUCTURE-   AXIAL SPACING BETWEEN TURNS =
```

rather than modern phrasing.

## Remaining differences

The current source still has a few sections that are not exact Fortran literal matches, including:

- minor header spacing and punctuation differences in some non-critical output blocks
- `AVERAGE POWER GAIN`, which does not currently branch to a distinct original-format header
- any parser/validation diagnostics from the Fortran inventory that are not part of output-file generation

## Document sections not generated by `src/output.c`

The Fortran inventory includes many parser, deck validation, and diagnostic messages that are still not produced by `src/output.c`, including:

- `FAULTY DATA CARD LABEL AFTER GEOMETRY SECTION`
- `ERROR - GF MUST BE FIRST GEOMETRY DATA CARD`
- `SEGMENT DATA ERROR`
- `PATCH DATA ERROR`
- `ERROR - N.G.F. IN USE.  CANNOT WRITE NEW N.G.F.`
- `N.G.F. tape file output`
- ROM2/ground-kernel warnings
- `SBF`, `TBF`, and `TRIO` segment connection errors
- main program startup/input diagnostics

These remain diagnostics and parser messages rather than output-file formatting sections.

## Notes

- This comparison is section-level; `tests/nec2_output_sections.md` documents Fortran output headings and `src/output.c` implements a mix of exact original headers and format-based branches.
- The source now has stronger original-format coverage in network excitation, normalized gain, near-field, and environment sections.
- The remaining mismatches are primarily in minor formatting detail rather than missing major sections.
